# Model contract v1: what the game code expects from each `.glb`

The art bible ([art-bible.md](art-bible.md)) says what each model looks like and why. This file is the exact
interface between the Blender output and the game code. If a model and this file disagree, the model is wrong (or
change this file and the code together).

## Common rules

- **Source is a script.** Every model is built by a Python script in `tools/blender/` run in Blender 4.5 background
  mode (`tools/blender/README.md`). The script builds from an empty scene and writes the `.glb` to
  `public/assets/models/`. Re-running it reproduces the file. No hand-edited `.blend` is the source of truth.
- **Units and axes:** metres, all transforms applied, exported with +Y up. Characters and props face **Blender −Y**
  (three.js +Z). The first-person viewmodel's barrel points **Blender +Y** (three.js −Z, away from the camera).
- **Materials:** Principled BSDF only (base colour, metallic, roughness, normal, emission, alpha). Textures are
  generated by the script (numpy) and packed into the glb, at most 1024² (2048² only for an entity body base colour).
  Names in `code font` below are material or object names the code looks up; keep them exact.
- **Export:** glTF Binary, no lights, no cameras. Sockets are Empties. Use `tools/blender/common.py`.
- **Report:** after exporting, run `tools/blender/inspect_glb.py` on the file; it writes
  `tools/blender/reports/<file>.json` (nodes, triangles, materials, bones, clips, bounds). Commit the report.
- **Preview:** render one `tools/blender/previews/<file>.png` (front three-quarter view, neutral light) for review.
- **Budgets** (triangles, LOD0): see each section. File size: props.glb ≤ 3 MB, each entity ≤ 4 MB, viewmodel ≤ 2 MB.

## Entities: `ent_skin_stealer.glb`, `ent_howler.glb`, `ent_smiler.glb`

- One armature named `<entity>_rig` (`skin_stealer_rig`, `howler_rig`, `smiler_rig`), one skinned body mesh, plus at
  most one more mesh (face or emissive parts). At most 64 bones, 4 influences per vertex. Bone names as in the art
  bible's skeleton for that entity.
- **Rest pose** stands on the floor at the origin, facing −Y, with the head inside the head hitbox.
- **Sockets (Empties):** `HIT_head` parented to the head bone at the head box centre; `HIT_body` parented to the
  spine (or pelvis) bone at the body box centre; `SOCKET_mouth` on the head; `SOCKET_eyes` (Smiler);
  `SOCKET_hand_R` (Skin-Stealer). `JS_CAM` is a **static** Empty, child of the armature object (not a bone): where the
  player's eye sits during the jump scare, about 0.5–0.6 m in front of the face at face height. (v1 keeps it static;
  the code adds the camera push and shake.)
- **Clips:** one Action per clip, named exactly as in the art bible's animation table, 30 fps, in place (the root does
  not travel), loops seamless (first frame = last frame). Locomotion clips are authored at these speeds, and the code
  scales playback by actual speed ÷ authored speed:

| Entity | Clip: authored speed (m/s) |
|---|---|
| Skin-Stealer | `walk_limp` 1.45 · `stalk` 2.55 · `lurch` 3.65 |
| Howler | `walk` 1.85 · `stalk` 3.2 · `lope` 4.55 · `run_search` 3.64 |
| Smiler | `glide` 1.6 · `glide_hunt` 3.3 (no feet: speed only sets the sway rate) |

- **Hitboxes in rest pose** (the code's boxes, height ranges in metres):

| Entity | Head box (height, width) | Body box (height, width × depth) |
|---|---|---|
| Skin-Stealer | 1.77–2.27, 0.55 | 0.30–1.77, 0.95 × 0.75 |
| Howler | 1.91–2.39, 0.45 | 0.275–1.91, 0.70 × 0.65 |
| Smiler | 1.605–2.155, 0.60 | 0.175–1.605, 0.85 × 0.75 |

- **Skin-Stealer extras:** shape keys `mask_slip` and `mouth_hole_open` on the body mesh (or a separate `mask`
  mesh). A node `disguise_bottle` (child of the armature object) that looks exactly like `prop_almond_water`; the
  code shows it while disguised and hides it when `reveal` starts. `reveal` (21 frames) unfolds the body from a
  crouched, folded pose low to the floor to full height.
- **Smiler extras:** body mesh `smiler_body` with material `smiler_void` (near-black `#030305`, alpha blend ≈ 0.85);
  face mesh `smiler_face` with material `smiler_glow` (white, emissive) on eyes and teeth (needle teeth, as in
  `concepts/smiler/B_turnaround.webp`), and shape keys `grin_wide`, `grin_open`, `eyes_narrow`, `face_tear`,
  `face_collapse`. The code drives the shape keys directly; clips need not animate them.
- **Howler extras:** `mouth_spark` is not needed (the code flashes a light at `SOCKET_mouth`). Three claws per hand.

## `vm_pistol.glb`: first-person pistol and arms

- Node `vm_root`; origin = grip centre; barrel along Blender +Y. Keep the code's proportions: slide about 0.27 m long
  with its top at z ≈ 0.04, suppressor Ø0.035 × 0.145 ending at y ≈ 0.30, weapon light under the barrel.
- An original pistol shape (**not** a copy of any real pistol: see `concepts/README.md`), three green tritium dots
  (material `tritium`, emissive `#68ffa2`), dark work gloves and olive jacket cuffs.
- Armature `vm_rig` with bones `gun_root`, `slide`, `trigger`, `magazine`, `hammer` and both arms (`upperarm_L/R`,
  `forearm_L/R`, `hand_L/R`; fingers optional). Clips: `idle` 60 (loop), `fire` 6 (slide back 0.042 m and home),
  `reload` 38, `empty` 4, `sprint` 20 (loop).
- Sockets: `SOCKET_muzzle` at the suppressor tip, `SOCKET_eject` at the ejection port, `SOCKET_light` at the weapon
  light lens.
- ≤ 10k triangles for the gun, ≤ 8k for the arms.
